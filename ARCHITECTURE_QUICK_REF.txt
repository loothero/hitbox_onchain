┌─────────────────────────────────────────────────────────────────────────┐
│                          DATA FLOW EXAMPLE                               │
└─────────────────────────────────────────────────────────────────────────┘

USER VOTES "UP":

1. 👤 User clicks UP button in browser
        ↓
2. 🌐 Client calls useVote().write({ args: [0], value: "0.001" })
        ↓
3. 🦊 MetaMask prompts user to confirm transaction
        ↓
4. 📝 Transaction submitted to blockchain
        ↓
5. ⛓️  Contract.vote(0) executes:
        • Validates direction ∈ [0,3] ✓
        • Validates msg.value >= 0.001 ETH ✓
        • Increments votes[currentTick][0]
        • Adds 0.001 ETH to pot
        • Emits VoteCast event
        ↓
6. 📡 VoteCast event broadcasted
        ├─→ Aggregator detects event
        │     • Updates internal vote tally
        │     • Waits for tick to end
        │
        └─→ Client event listener refetches state
              • Pot updates in UI
              • Vote count increments
        ↓
7. ⏰ 3 seconds pass, tick ends
        ↓
8. 🤖 Aggregator detects tick ended:
        • Tallies final votes
        • Determines winner (UP wins!)
        • Submits finalizeTick(tick, 0) transaction
        ↓
9. ⛓️  Contract.finalizeTick() executes:
        • Marks tick as finalized
        • Advances to next tick
        • Updates lastMover
        • Emits TickFinalized event
        ↓
10. 📡 TickFinalized event broadcasted
        └─→ Client updates:
              • Tick number increments
              • Cursor moves up in visual
              • New countdown starts
